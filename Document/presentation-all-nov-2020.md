## Slide 2: Problem Statement

- Programming is hard
- Even though there are more than 5000 programming languages
- Unavailability of compiler using natural languages
- Evolution of new idea: **Why can't we use Natural language for computing?**

---

## Slide 3: Scope of the Project

- Make humans to understand
- Reduces the complexity of programming
- Makes programming more attractive for beginners
- Can be introduced as an introductory course
- Self-documenting

---

## Slide 4: Why This Project?

- For easy communication with computer
- Time saving
- Easy to understand by anyone
- Easy to learn
- No need of HLL
- Less structured than HLL

## Slide 6: Proposed Idea

**Artificial Level Language:**
- Directly use of Natural Language
- Uses English or other spoken languages
- **Upper level than High-Level Language (HLL)**

### Language Hierarchy:

```
┌─────────────────────────────────────┐
│  Artificial Level Language (ALL)    │  ← NEW TIER
├─────────────────────────────────────┤
│  High Level Language (HLL)          │
├─────────────────────────────────────┤
│  Assembly Level Language            │
├─────────────────────────────────────┤
│  Machine Level Language             │
└─────────────────────────────────────┘
```

## Slide 7: Proposed Idea (cont.)

- This is not significantly tightened HLL
- Grammatically correct statements
- Uses a Trans-Compiler or TranScripter

## Key Insights

This presentation (Nov 2020) represents the earliest public articulation of the ALL concept, approximately 3 years before the IEEE paper (ICCC 2023).

### Differences from Later Work:
- **2020 framing:** Introductory course, educational focus
- **2023 framing:** 6th generation of computing, formal tranSMachine architecture
- **Added concepts:** ACHU's Programming Language, tranSMachine (tranScripter + transCompiler)

### Core Ideas That Remained Constant:
- Natural language as programming input
- ABOVE high-level languages in hierarchy
- Grammar not strictly required
- Uses tranScripter/transCompiler approach
