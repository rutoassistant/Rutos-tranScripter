## Key Concepts

### Artificial Level Language (ALL)
- Proposed as a new tier above High-Level Languages (HLL)
- Uses natural language (English) for programming
- Grammatically correct or incorrect input supported
- Part of "6th generation of computing machines"

### tranSMachine Architecture
- **tranScripter**: Converts natural language to Python code
- **transCompiler**: Future work (not yet implemented)

### JAVS
Name derived from developers:
- **J** - Julien Joseph Thomas
- **A** - Muhammed Anas
- **V** - Vishnu Suresh
- **S** - Sayu Sajeev
